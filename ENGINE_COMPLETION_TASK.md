# Quantum — tarefa única de conclusão da engine

Objetivo: levar a Quantum de uma engine funcional para uma engine de produção, completando os sistemas abaixo sem quebrar os recursos existentes.

## Regras de execução

- Usar uma única árvore de build: `build/` ou `$QUANTUM_BUILD_DIR`.
- Nunca iniciar `quantum-editor.exe` para validar mudanças.
- Validar cada fase com MSVC, um executável headless e, para renderização, uma captura PNG.
- Não considerar enum, shader ou header como implementação até existir definição, chamada no ciclo real e prova executável.
- Atualizar este arquivo na mesma alteração que concluir cada item.
- Escopo desta task: UI/Slate e seus testes estão deliberadamente fora; o trabalho segue apenas nas demais áreas da engine.

- [x] concluído e verificado
- [~] parcialmente implementado ou aguardando validação
